# Oxford Cove by IMAN — glemO International

Landing page de alta conversão e apresentação de luxo para o lançamento imobiliário **Oxford Cove by IMAN Developers** em Dubai (JVC District 11), desenvolvida para a **glemO International**.

## 🚀 Tecnologias
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lucide Icons**

## 🛠️ Como rodar o projeto

```bash
# Instalar dependências
npm install

# Rodar o servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.
